# Security

Nivel processes microphone audio locally and never sends audio or data over the network.

If you find a security issue, please report it privately through [GitHub Security Advisories](https://github.com/machina-sports/nivel/security/advisories/new) instead of opening a public issue, or email Mateus Pinheiro at [mateus.pinheiro@machina.gg](mailto:mateus.pinheiro@machina.gg). We will acknowledge the report, work on a fix, and credit you when it is released, unless you prefer otherwise.
